
                    STANCEBOY MOTORS WEBSITE
                    PART 3 - WEB DEVELOPMENT


1. PROJECT OVERVIEW

StanceBoy Motors is a fictional car customization and performance 
tuning business based in Pretoria, Gauteng. 

This website was built to showcase the company's services, allow 
customers to submit enquiries and applications, and display the 
company's builds through an interactive gallery.

Target Audience: Car enthusiasts in Pretoria and Gauteng looking 
for stance, performance upgrades, and vehicle servicing.

2. WEBSITE FEATURES - PART 3 REQUIREMENTS

✓ Responsive Design: 
  Website adapts to Desktop, Tablet, and Mobile using CSS Media Queries

✓ Enhanced Functionality with JavaScript:
    - Form Validation: Both Enquiry and Volunteer forms validate user 
    input before submission. Shows error messages for invalid fields.
    - Interactive Element: Image Gallery Lightbox. Click any image in 
    "Our Builds" section to view it full screen with overlay.

✓ SEO Optimization:
    - Unique Meta Descriptions and Titles for each page
    - Descriptive Alt Text for all images
    - Semantic HTML structure with H1, H2, H3 tags
    - Open Graph tags for social media sharing

✓ Consistent Branding:
    - Color Scheme: Black #0a0a0a, Dark Grey #111, Red #ff1a1a
    - Font: Arial, Helvetica, sans-serif
    - Logo and styling consistent across all 5 pages

4. HOW TO RUN THE WEBSITE

1. Download all files and folders
2. Keep the folder structure the same
3. Open index.html in any modern web browser
4. No server or installation required - this is a static website

For best experience, view on Chrome, Firefox, or Edge.

5. TECHNOLOGIES USED

- HTML5: Semantic structure
- CSS3: Styling, Flexbox, Grid, Media Queries
- Vanilla JavaScript: DOM Manipulation, Event Listeners, Form Validation
